# وين دواي؟ — Windawai

المشروع الخيري الذي يحمل اسم «وين دواي؟» يهدف إلى تسهيل العثور على الأدوية وربط المرضى بالصيدليات في السودان.

## ما تم تجهيزه
- واجهة عربية RTL متجاوبة للهواتف والكمبيوتر.
- البحث مع تصحيح الأخطاء الإملائية الشائعة.
- عرض التوفر والسعر ورقم التواصل والموقع.
- طلب تنبيه عند عدم التوفر.
- تسجيل الصيدلية مباشرة وإظهارها في النسخة التجريبية.
- بوابة الصيدلية لتحديث حالة الدواء والسعر.
- لوحة الإدارة والإحصاءات والتعليقات.
- PWA/manifest وservice worker.
- مخطط PostgreSQL/Supabase كامل مع RLS كبنية إنتاجية.
- ملفات أمن ونشر واختبار.

## ما لا يمكن أن يحدث من GitHub Pages وحده
GitHub Pages لا يوفر قاعدة بيانات مركزية أو حسابات آمنة أو إشعارات خادم. لذلك `database.sql` هو خطوة الربط التالية، وليس من الصحيح الادعاء أن هذه الخدمات تعمل فعلياً قبل إنشاء Backend.
