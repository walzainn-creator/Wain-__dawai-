# وين دواي؟ — Windawai

منصة خيرية للبحث عن الأدوية المتوفرة في الصيدليات في السودان.

## الملفات

- `index.html` — واجهة المستخدم المتجاوبة مع الهاتف والكمبيوتر.
- `app-config.js` — إعدادات عامة غير سرية.
- `manifest.json` — تجهيز الواجهة كتطبيق ويب قابل للتثبيت على الهاتف.
- `.nojekyll` — لتجنب مشاكل GitHub Pages مع الملفات الثابتة.
- `404.html` — صفحة الخطأ.
- `schema.sql` — مخطط قاعدة بيانات PostgreSQL/Supabase للنسخة الحقيقية.

## النشر الحالي

المشروع يعمل كواجهة GitHub Pages. GitHub Pages يستضيف الملفات الثابتة، لذلك لا يمكن الاعتماد عليه وحده لتشغيل تسجيل دخول حقيقي أو قاعدة بيانات أو إشعارات مركزية.

## النسخة النهائية الحقيقية

لتحويل المشروع إلى نظام متعدد المستخدمين:
1. إنشاء مشروع Supabase.
2. تشغيل `schema.sql`.
3. إضافة المصادقة وحسابات الصيدليات والإدارة.
4. ربط `index.html` بواجهة Supabase باستخدام المفتاح العام فقط.
5. منع أي مفتاح service-role أو كلمة مرور من الظهور في GitHub.
6. إضافة خدمة إشعارات حقيقية للبريد/SMS/WhatsApp حسب الخدمة المتاحة في السودان.
7. اختبار صلاحيات المستخدم والصيدلية والمدير قبل فتح التسجيل العام.

## الأدوار

- المريض/الزائر: البحث، الموقع، الاتصال بالصيدلية، طلب التنبيه، التعليق.
- الصيدلية: إدارة بياناتها والأدوية والأسعار وحالة التوفر.
- المدير: اعتماد الصيدليات، إدارة الأدوية، الرد على التعليقات، متابعة الإحصاءات وطلبات التنبيه.

## ملاحظة مهمة

هذه الحزمة لا تدّعي أن قاعدة البيانات أو الإشعارات الحقيقية تعمل قبل ربط خدمة Backend. هذا متعمد لتجنب نشر نظام يوهم المستخدمين بأن بياناتهم محفوظة مركزياً بينما هي ليست كذلك.
